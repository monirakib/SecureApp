{# RSA KEY ROTATION #}
⚿ SYSTEM RSA KEYS

RSA keys encrypt user profile data and ECC private keys.

Rotation generates new RSA keys and re-encrypts all {{ user_count }} user records. Destructive operation.

{# HMAC KEY ROTATION #}
⬡ HMAC KEYS

HMAC keys verify data integrity on posts, messages, and user records.

After rotation, all existing records (posts, messages, tips, dead drops, comments, documents, and user accounts) are automatically re-signed with the new keys. No data is lost or invalidated.
