KEY MANAGEMENT

SYSTEM RSA KEYS

RSA keys encrypt user profile data and ECC private keys.

Rotation will generate new RSA keys and re-encrypt all {{ user_count }} user records.

HMAC KEYS

HMAC keys are used for data integrity verification on posts, messages, and user records.

After rotation, existing HMAC signatures will not match until data is re-written. New data will use the new keys automatically.
